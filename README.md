# Microsomativa 2 - Portfólio Daft Punk
## Sobre o Projeto

Este projeto foi desenvolvido para a Microsomativa 2 da disciplina de Programação Front-End, realizado em dupla.
O site apresenta um portfólio sobre a banda Daft Punk, reunindo informações sobre sua história, integrantes, álbuns, projetos e outros conteúdos.

---

## Objetivo

O objetivo desse projeto é aplicar na prática os conhecimentos de desenvolvimento web utilizando o bootstrap.
- Layout Resposivo em diferentes telas
- Cards, Nav e Botões
- Componentes

---

## Tecnologias Utilizadas

- HTML 5
- CSS 3
- JavaScript
- Bootstrap 5
- Git/Github

---

## Estrutura do Repositorio

```text
dossie_daftpunk/
├── index.html             # Página principal (Home)
├── pages/                 # Outras páginas HTML do site
│   ├── sobre.html
│   ├── homework.html      # Informações de cada um dos álbuns
│   ├── descovery.html
│   └── human-after-all.html
│   └── random-access-memories.html
├── src/                   # Código-fonte dos recursos visuais e lógicos
│   ├── css/
│   │   ├── style.css      # Estilos gerais/globais
│   ├── js/
│   │   ├── main.js        # Scripts gerais (configuração "automática" dos cards)
│   └── img/            # Capa dos álbuns e músicas
├── .gitignore
├── README.md
└── package.json
```

---

## Como Executar o Projeto

1. Clonar o repositório
```text
git clone URL_DO_REPOSITÓRIO
```

2. Entrar na pasta do projeto
```text
cd dossie-daftpunk
```

3. Instalar as dependências
```text
npm install ou npm i
```

4. Abrir o projeto
Abra o arquivo index.html em um navegador de sua preferência.
